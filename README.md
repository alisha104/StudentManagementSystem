# StudentHub — Student Management System

## Project Overview

StudentHub is a responsive web application developed to demonstrate JavaScript fundamentals through a practical student record management system. It provides a simple dashboard where users can register students and manage their information efficiently.

## Objective

The objective is to apply HTML, CSS, JavaScript, functions, arrays, objects, DOM manipulation, and events to develop a functional and interactive web application.

## Technologies Used

- HTML5 — webpage structure and form elements.
- CSS3 — styling, responsive layouts, and dashboard design.
- JavaScript — application logic, validation, event handling, and dynamic updates.
- localStorage — saving student records in the browser.

## Features

- Add student records.
- Validate form inputs and prevent duplicate email addresses.
- Display student information in a dynamic table.
- Edit existing records.
- Delete records after confirmation.
- Search by student name or email.
- Filter records by grade.
- Sort student names alphabetically in ascending or descending order.
- Display dashboard statistics.
- Preserve records after refreshing the page using localStorage.

## JavaScript Concepts Used

The project uses variables, constants, functions, arrays, objects, conditional statements, loops, array methods, DOM selection, dynamic element creation, and event listeners. Methods such as `filter()`, `find()`, `findIndex()`, `some()`, `map()`, and `sort()` help manage and display student records.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser, or use the Live Server extension.
4. Register students and explore the search, filter, edit, delete, and sorting features.

## Screenshots

Project screenshots will be stored in the `screenshots` folder. They will demonstrate the dashboard, registration form, and student records.

## Limitations and Future Improvements

This project stores records in the current browser's localStorage. It does not include user authentication, a shared online database, or automatic synchronization between devices. Future improvements could include secure login, database integration, data export, and student attendance tracking.
