# StudentHub – Project Documentation and Reflection

## 1. Project Overview

StudentHub is a Student Management System developed as part of my Week 5 JavaScript project. The purpose of this website is to make it easier to manage basic student information. It provides a form to enter student details and a table to view the saved records.

## 2. Features Implemented

The project includes the following features:

- Adding new student records.
- Editing and deleting existing records.
- Searching for students by name or email.
- Filtering records by grade.
- Sorting student names alphabetically.
- Validating form inputs before saving.
- Displaying student statistics on the dashboard.
- Saving records using browser localStorage.

## 3. Technologies Used

I used HTML to create the page structure, CSS to style the website, and JavaScript to make its features interactive. JavaScript concepts used in the project include variables, functions, arrays, objects, conditions, loops, array methods, DOM manipulation, and event listeners. JSON and localStorage are used to save and retrieve records in the browser.

## 4. Challenges and Solutions

One important part of the project was connecting the form with the student table. The website needs to display the latest information after a record is added, edited, or deleted. A rendering function helps update the table and dashboard.

Form validation is another important feature because it checks the information entered by the user before saving it.

## 5. What I Learned

Through this project, I practised using JavaScript to respond to user actions and update webpage content. I also learned how search, filtering, sorting, and localStorage can make a simple website more useful.

## 6. Future Improvements

In the future, I would like to connect the website to a database so that records can be shared across devices. I could also add login functionality and an option to export records.
